TIME OFF TRACKER 1.3
====================

Java 21 + Swing + FlatLaf + SQLite

BUILD
-----
1. Open Terminal in this project folder.
2. Run: mvn clean package
3. Run: java -jar target/time-off-tracker.jar

MAC APP BUILD
-------------
After giving the script executable permission once, double-click:
Build Time Off Tracker.command

It builds the JAR and creates:
dist/Time Off Tracker.app

NEW IN 1.3
----------
- Replaces the simple Dark Mode toggle with a full Appearance window.
- Adds 20 selectable themes including everyday and holiday themes.
- Adds Follow System, Light, Dark, Midnight, Graphite, Ocean, Forest, Warm Sand, Slate Blue, and High Contrast.
- Adds Halloween, Thanksgiving, Christmas, New Year, Valentine's Day, St. Patrick's Day, Easter/Spring, Memorial Day, Independence Day, and Labor Day themes.
- Adds visual theme previews.
- Adds optional automatic seasonal theme switching.
- Allows each seasonal theme to be enabled or disabled independently.
- Automatically returns to your selected base theme after a seasonal window ends.

DATA
----
Your database remains outside the project at:
~/.timeofftracker/timeoff.db

Replacing/rebuilding the application does not delete that database.
